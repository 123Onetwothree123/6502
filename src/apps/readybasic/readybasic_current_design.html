Current Syntax And Statement Behavior

ReadyBASIC commands use raw visible text. Stored lines remain readable, and LIST shows the command text.

!COMMAND first,arg,arg

The command name follows !. The first argument is separated by whitespace, and later arguments use commas. A leading comma after the command name is rejected.

IF normalization: IF 1 THEN !PING P% works, but stores/lists as IF 1 THEN :!PING P% so BASIC reaches the normal statement dispatcher.
  • YesImmediate mode, for example !PING P%.
  • YesStored program line start.
  • YesAfter :, for example PRINT "A":!PING P%.
  • YesInside a FOR/NEXT body as a normal statement.
  • YesAfter IF ... THEN, through the lean crunch rewrite.
  • TextInside strings, REM, and DATA; not rewritten or dispatched.
  • NoInside expressions, PRINT lists, or FOR clauses.
  • NoELSE is not native BASIC V2 and is not added by ReadyBASIC.

Command Families

These are implementation examples of command shapes the spine supports, not the final product command catalog.

Scalar Outputs low overlay

PINGADD16

Prove integer output variables, numeric expression parsing, output clearing, and scalar commit.

String Transfer/Transform low overlay

STRUP

Captures string variables or quoted literals, stages transformed bytes, and lets resident code allocate the BASIC string result.

Hidden Banked Worker hidden

HCRC

Runs worker code under BASIC ROM RAM in the $A800 hidden overlay slot and returns an integer result.

Integer Array Transfer low overlay

SUMAIRANGEAI

Uses explicit base element plus count, for example A%(0),N, to read or write integer arrays.

Persistent REU Handles REU data

BUFNEWBUFFILLBUFFREESCRCAPSCRPUT

Returns small BASIC integer handles for persistent REU-backed buffers and typed screen text+color resources.

Temporary REU Workspace temp pages

TEMPSCRATCH

Allocates and immediately frees pages, proving temporary workspace without persistent state leaks.

Error/Failure Contract error path

FAIL

Clears output first, then reports ?RB ERROR n without committing stale results.

Runtime Introspection header

FREEMEM

Prints live BASIC free bytes and refreshes the header value without returning an output variable.

ReadyOS Yield system

EXIT

Manual prompt command that saves BASIC runtime state, restores vectors, and returns through the ReadyOS shim.

Command Overlay Loading And Files Involved

There is one ReadyBASIC app executable: bin/readybasic.prg. There is not one PRG or executable file per command. The command overlays are linker segments inside that one PRG load image.

Load Image To Runtime

1

Link

LOWPACK, HIDDENPACK, and REGSEED are embedded in one PRG.

2

Cold Seed

Hidden helper copies registry/header to bank $44 and command code to bank $45.

3

Release

BASIC may later own former load-image ranges such as $5000+.

4

Fetch

Each command descriptor tells the loader which bank $45 bytes to copy.

5

Call

Low code runs under BASIC ROM at $A900; hidden code runs at $A800.

BASIC Free RAM And Growth Strategy

Stock C64 BASIC V2 starts at $0801 with top at $A000, giving about 38911 bytes free. ReadyBASIC relocates BASIC to $1C01 with top at $A000. On an empty ReadyBASIC workspace, variables begin at $1C03, so the practical empty BASIC free space is $A000 - $1C03 = 33789 bytes.

How To Add Many More Commands

  • Keep the resident core below $1C00; every resident byte is permanent C64 RAM pressure.
  • Put implementation code in packed REU code banks and copy it into existing overlay slots only when invoked.
  • Reuse existing signatures and commit paths where possible.
  • Keep descriptors in the REU registry, not in resident RAM.
  • Expose large or persistent state as BASIC integer handles backed by dynamic REU banks.
  • If bank $45 becomes crowded, extend the registry for more packed code banks instead of lowering BASIC top.

Command Dispatch Pipeline

Match

Execute hook peeks without mutating TXTPTR. Non-ReadyBASIC statements tail-call ROM.

Parse

Command name normalizes into $C4A0; descriptors are scanned from REU bank $44.

Execute

Code is fetched from bank $45 into $A900 or $A800, then writes result frame $C300.

Commit

Resident prints ?RB ERROR n on failure or commits integer, string, or array results.

Cold Boot, EXIT, And Warm Resume

Cold Boot

1

Load

ReadyOS loads readybasic.prg at $1000.

2

Copy

Entry copies hidden helper seed to $A000 and a visible shadow to $C280, then bridge seed to $C000.

3

Relocate

Resident installs hooks and relocates BASIC to $1C01 with top at $A000.

4

Seed REU

Bank $44 gets header/descriptors; bank $45 gets packed command code.

5

READY

ReadyBASIC clears/redraws the screen, prints its banner, and enters BASIC_READY.

Manual EXIT And Warm Resume

1

EXIT

Manual prompt EXIT stores READY-mode bridge and entry magic.

2

Snapshot

Zero page and stack page are saved to REU bank $44, while SP, mode, and guards remain in bridge metadata.

3

Yield

Original vectors are restored and ReadyBASIC jumps to shim return $C80C.

4

Restore

Warm entry restores $A000 from $C280, reinstalls vectors, and re-marks REU ownership.

5

Resume

Runtime state is restored, live BASIC pointers are preserved, and the screen is redrawn.

Warm resume does not cold-reset FRETOP, VARTAB, ARYTAB, or STREND. Those live BASIC pointers must survive with variables, arrays, and string heap state intact.

Hard Invariants

  • Boot ReadyBASIC through normal ReadyOS run/profile flows.
  • BASIC_START remains $1C01.
  • $1C00 remains zero before stored-program RUN.
  • RESIDENT stays below $1C00.
  • BRIDGE stays below $C600.
  • $C600-$C7FF is shared ReadyOS REU metadata.
  • $C800-$C9FF is ReadyOS shim ABI.
  • Warm resume restores $A000 from the refreshed visible shadow at $C280 before hidden helper calls.
  • Warm resume does not cold-reset BASIC heap or variable pointers.
  • ReadyBASIC-owned vectors are restored before yielding to ReadyOS.
  • Non-ReadyBASIC statements tail-call ROM with unmutated TXTPTR.
  • Output variables are cleared before command execution.
  • String heap writes happen only in visible resident code.
  • Acceptance re-entry uses launcher menu navigation, not direct app-bank hotkeys.
