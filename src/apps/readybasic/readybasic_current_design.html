ReadyBASIC Current Design

Readable BASIC commands backed by assembler modules, REU registries, and three 2KB under-ROM submodule slots. The important runtime fact: after initialization, BASIC owns $2AC1-$9FFF; command code and registries live in REU and under BASIC ROM.

Post-BASIC Memory Map

$1000-$1102
Entry. Cold/warm discriminator and startup handoff.
$1200-$2ABB
Resident. Parser hooks, BASIC ROM calls, REU DMA wrappers, command dispatch, commit, native language features.
$2AC1-$9FFF
BASIC workspace. Program text, variables, arrays, strings, and reclaimed cold seed bytes.
$A000-$BFFF
BASIC ROM visible, RAM underneath. Common helper plus slots 0, 1, and 2 when RAM is banked in.
$C000-$C5FF
Bridge and frames. Bridge through $C1F6, call/result frames, descriptor buffer, command buffer, and page/load buffer.
$C600-$C9FF
ReadyOS territory. REU allocation metadata and shim ABI. ReadyBASIC only marks bank ownership at $C600+$44/$45.
$D000-$FFFF
I/O and ROM. VIC/SID/CIA/REU registers, KERNAL ROM, and normal C64 banking rules.

Descriptor Meaning

Descriptors are module-aware records: command id, module id, payload offset and size in REU bank $45, submodule id, overlay id, slot mask, generation, runtime destination, entry offset, signature id, and command name.

Slot Masks

1 = slot 0, 2 = slot 1, 4 = slot 2. Spans combine adjacent bits.

REU $44

Registry and runtime state: header, call/result scratch, handles, zero-page and stack snapshots, descriptors, reserved module metadata, and the 48KB typed heap.

REU $45

Payload bank: built-in module bytes at $0000-$085B, disk sample payloads at $3000, $3200, $3300, and $3400.

Warm Resume

Warm resume reuses REU registries and payloads. It must not trust cold seed bytes that BASIC now owns.

Command Call Flow

1. ParseResident code validates syntax and fills the call frame.
2. LookupDescriptor pages stream from REU $44 through $C500.
3. FetchREU $45 copies the needed module payload only if not resident.
4. ExecuteRAM under BASIC ROM is mapped in and the worker runs.
5. CommitResident code restores banking and commits the result frame.
