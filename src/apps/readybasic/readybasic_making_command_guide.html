Making Commands

A ReadyBASIC command is a resident parser signature plus a 32-byte REU descriptor plus assembler payload bytes copied into one or more under-ROM slots. Keep resident growth low; put command policy and worker code in modules.

Command Anatomy

ParserResident signature validates syntax and fills $C200.
Descriptor32 bytes in REU $44:$1000 name the module, payload, slot mask, and signature.
PayloadAssembler bytes live in REU $45, built in or disk-loaded.
SlotPayload runs under BASIC ROM at $A800, $B000, $B800, or a span.
CommitWorker writes $C300; resident code restores banking and commits results.

Descriptor Bytes

BytesMeaningAuthoring rule
0Command idStable internal id.
1Module idModule 1 is system/default; module 2 is proof/loader.
2-5REU payload offset and sizeAlways bank $45 in the current implementation.
6-9Submodule, overlay, slot mask, generationUse overlay id 0 for normal submodules.
10-13Runtime destination and entry offsetOffsets are from $A000 and from payload entry.
14-31Signature id and uppercase nameName field is 16 bytes max.

Name Safety

Command names are readable BASIC text. Avoid keyword substrings that tokenize inside names. Use ZMODLD, not ZMODLOAD.

Choose A Layout

NeedLayoutExample
Common system commandModule 1, slot 0 at $A800ZADD16, BUFNEW
Independent proof or utility familyModule submodule in slot 1 or slot 2ZSLOT1, ZSLOT2
4KB workerOne payload spanning slots 1+2ZSPAN, ZDM2S
Stable manager plus variantsManager in slot 1, overlays through slot 2ZOVL1, ZOVL2, ZDOV1, ZDOV2
Large exclusive workerFull slots 0+1+2 spanAllowed, but it cannot assume slot-0 helpers remain resident.

Built-In Command Steps

  1. Add a CMD_* id and reuse a SIG_* where possible.
  2. Write a small resident parse_sig_* only for syntax, ROM expression evaluation, and frame setup.
  3. Place worker code in the correct under-ROM segment.
  4. Emit a module-aware descriptor with the right slot mask and REU payload offset.
  5. Add VICE coverage for success, errors, expression form if supported, and residency if relevant.

Macros

CMD_LOW, CMD_LOW_ALL, CMD_SLOT1, CMD_SLOT2, CMD_SPAN, CMD_OVL1, and CMD_OVL2 are source conveniences. They all produce the same descriptor ABI.

Minimal Source Pattern

CMD_LOW CMD_ZADD16, SIG_ZADD16, cmd_zadd16_low, cmd_zadd16_low_end, "ZADD16"

cmd_zadd16_low:
        ; read CF_* fields from $C200
        ; write RF_* fields to $C300
        rts
cmd_zadd16_low_end:

Disk Module Pattern

StepRule
GenerateUse build_support/build_readybasic_disk_modules.py to produce PRG files with load address $C500 and magic RBM!.
RegisterZMODLD(name$) copies descriptors to REU $44 and payloads to $45.
ExecuteCommands run from REU-backed payloads, not from the temporary $C500 load buffer.
TestThe suite should load RBM1/RBM2 and assert single-slot, span, and overlay commands.

Commit Checklist

Resident remains below BASIC_START; bridge remains below $C200; frame use stays in $C200-$C5FF; $C600-$C9FF is untouched except bank ownership marks; slot payloads fit; descriptor offsets match REU payloads; names avoid tokenizer collisions; verification boots normal ReadyOS.
