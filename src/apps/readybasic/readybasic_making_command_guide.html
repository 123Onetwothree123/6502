Naming Rules

ReadyBASIC names are visible BASIC text after !, not private tokens. Avoid substrings that C64 BASIC can tokenize inside the command name.

Proof/demo commands use Z.... Array demos use NUM instead of INT. Historical names like PING, ADD16, STRUP, HCRC, SUMAI, and RANGEAI are not aliases.

The current proof/demo names are ZECHO1, ZADD16, ZHIDDENRAM, ZSUMNUMARRAY, ZRANGENUMARRAY, ZTEMPSCRATCH, and ZFAIL. The useful string commands are UPPER and LOWER.

Descriptor Shape

Descriptors are cold-seeded into REU bank $44:$1000-$1FFF. Runtime lookup fetches one 256-byte page, scans eight descriptors, then copies the match to RB_DESC_BUF.

.macro CMD_LOW id, sig, label, endlabel, name
        .byte id, RB_CMD_F_LOW
        .word label - __LOWPACK_RUN__ ; offset in REU bank $45
        .word endlabel - label        ; copy length
        .word 0, 0
        .word label - RB_LOW_BASE     ; run offset from $A900
        .word 0
        .byte sig, .strlen(name)
        .byte name
        .res 16 - .strlen(name), 0
.endmacro
.macro CMD_LOW_ALL id, sig, label, name
        .byte id, RB_CMD_F_LOW
        .word 0                    ; whole LOWPACK
        .word __LOWPACK_SIZE__
        .word 0, 0
        .word label - RB_LOW_BASE
        .word 0
        .byte sig, .strlen(name)
        .byte name
        .res 16 - .strlen(name), 0
.endmacro

.macro CMD_HIDDEN id, sig, label, endlabel, name
        .byte id, RB_CMD_F_HIDDEN
        .word 0, 0
        .word label - __HIDDENPACK_RUN__
        .word endlabel - label
        .word 0
        .word label - RB_HIDDEN_BASE
        .byte sig, .strlen(name)
        .byte name
        .res 16 - .strlen(name), 0
.endmacro

Small Commands

ZECHO1

low overlayoutput int

Minimum output-command skeleton: parse OUT%, stage integer 1, commit.

parse_sig_zecho1:
        jsr rb_parse_out_int
        rts

cmd_zecho1_low:
        lda #0
        sta RF_STATUS
        lda #RB_VAL_INT
        sta RF_TAG
        lda #1
        sta RF_VAL_LO
        lda #0
        sta RF_VAL_HI
        rts
cmd_zecho1_low_end:
CMD_LOW CMD_ZECHO1, SIG_ZECHO1,
        cmd_zecho1_low, cmd_zecho1_low_end, "ZECHO1"

ZADD16

low overlaytwo numeric inputs

Proves BASIC ROM expression parsing in resident code, then simple arithmetic in the overlay.

parse_sig_zadd16:
        jsr rb_parse_num0
        jsr rb_parse_num1
        jsr rb_parse_out_int
        rts

cmd_zadd16_low:
        clc
        lda CF_NUM0_LO
        adc CF_NUM1_LO
        sta RF_VAL_LO
        lda CF_NUM0_HI
        adc CF_NUM1_HI
        sta RF_VAL_HI
        lda #0
        sta RF_STATUS
        lda #RB_VAL_INT
        sta RF_TAG
        rts
CMD_LOW CMD_ZADD16, SIG_ZADD16,
        cmd_zadd16_low, cmd_zadd16_low_end, "ZADD16"

String Commands

UPPER and LOWER share parse_sig_string_out. The overlay transforms bytes into RF_STR_BUF; resident code owns BASIC string heap allocation.

parse_sig_string_out:
        jsr rb_parse_string_value
        jsr rb_parse_out_string
        rts

cmd_lower_low:
        lda #0
        sta RF_STATUS
        lda #RB_VAL_STRING
        sta RF_TAG
        lda CF_STR_LEN
        sta RF_STR_LEN
        ldy #0
@loop:
        cpy CF_STR_LEN
        beq @done
        lda CF_STR_BUF,y
        cmp #'A'
        bcc :+
        cmp #'Z' + 1
        bcs :+
        clc
        adc #$20
:       sta RF_STR_BUF,y
        iny
        jmp @loop
@done:
        rts
CMD_LOW CMD_UPPER, SIG_UPPER,
        cmd_upper_low, cmd_upper_low_end, "UPPER"
CMD_LOW CMD_LOWER, SIG_LOWER,
        cmd_lower_low, cmd_lower_low_end, "LOWER"

The source also handles shifted C64 letter bytes. Tests assert ASC() values because visual case depends on the active C64 charset.

Array And Hidden Examples

ZHIDDENRAM

Uses CMD_HIDDEN, fetches code into $A800, maps RAM under BASIC ROM, runs a checksum-like worker, and restores banking.

CMD_HIDDEN CMD_ZHIDDENRAM, SIG_ZHIDDENRAM,
           cmd_zhiddenram_hidden, cmd_zhiddenram_hidden_end,
           "ZHIDDENRAM"

ZSUMNUMARRAY

Uses an explicit base element plus count: !ZSUMNUMARRAY A%(0),3,S%. Resident code resolves the array pointer before the overlay runs.

parse_sig_zsumnumarray:
        jsr rb_parse_int_array_input
        jsr rb_parse_out_int
        jsr rb_resolve_int_array_input_ptr
        rts

ZRANGENUMARRAY

Output-array sibling for ZSUMNUMARRAY. It proves the result-frame path for writing several integer elements after the command has succeeded.

REU Handle Commands

BASIC sees a small integer handle. Canonical descriptors live in REU bank $44:$0800-$09FF, the bitmap at $44:$0C00, and data in the 48KB typed heap at $44:$4000-$FFFF.

CommandPattern
BUFNEWAllocate pages, store type-1 descriptor, return one-based handle.
BUFFILLValidate type-1 buffer handle, fill pages through $C500.
BUFFREEFree any valid handle type and clear metadata.
SCRCAPAllocate type-2 screen text+color handle and stash text/color RAM.
SCRPUTValidate type-2 handle and restore text/color RAM from slot-128 lookup.
 
cmd_bufnew_low:
        jsr rb_handle_alloc
        rts

cmd_scrput_low:
        jsr rb_screen_handle_validate
        lda RF_STATUS
        beq :+
        rts
:       jsr rb_screen_load_text
        jsr rb_screen_load_color
        lda #0
        sta RF_STATUS
        lda #RB_VAL_NONE
        sta RF_TAG
        rts
CMD_LOW_ALL CMD_BUFNEW, SIG_BUFNEW, cmd_bufnew_low, "BUFNEW"
CMD_LOW_ALL CMD_BUFFILL, SIG_BUFFILL, cmd_buffill_low, "BUFFILL"
CMD_LOW_ALL CMD_BUFFREE, SIG_BUFFREE, cmd_buffree_low, "BUFFREE"
CMD_LOW_ALL CMD_SCRCAP, SIG_SCRCAP, cmd_scrcap_low, "SCRCAP"
CMD_LOW_ALL CMD_SCRPUT, SIG_SCRPUT, cmd_scrput_low, "SCRPUT"

The handle lesson is to keep BASIC-visible values small, keep canonical resource metadata in REU, and validate handle type at command boundaries. BUFFILL accepts only type-1 buffer handles; SCRPUT accepts only type-2 screen text+color handles; BUFFREE frees any valid type.

Naming Lessons And Add-Command Checklist

  1. Choose a tokenizer-safe name.
  2. Add command id and signature id.
  3. Add or reuse a parser signature that fills the call frame and clears outputs.
  4. Add a low or hidden worker that writes the result frame only on success.
  5. Add a descriptor entry; use CMD_LOW_ALL only when shared helpers require the full low pack.
  6. Keep resident growth minimal; prefer REU metadata and existing scratch pages.
  7. Add direct, stored-program, error-path, and resume/slot coverage.
  8. Update Markdown and HTML docs with measured map values after tests pass.
