ReadyBASIC Making Command Guide

A teaching guide for how current bare COMMAND(...) examples are wired into descriptors, parser signatures, low overlays, hidden overlays, and REU handles.

What You Are Building

A ReadyBASIC command is not just one assembler routine. It is a contract between BASIC text, resident parser code, a cold REU descriptor, and an overlay worker copied into C64 RAM only when needed.

Native PROC/FUNC routines are not plugin commands. They are ordinary BASIC program text called by EXEC, so they do not need descriptors, command ids, signature ids, LOWPACK, HIDDENPACK, or REU bank $45 code bytes. Use this guide when adding new descriptor-backed command overlays.

1. User Types

ZADD16(4,5,A%) is visible BASIC text. The command name must survive C64 tokenization.

2. Lookup

ReadyBASIC pages descriptor records from REU bank $44 and finds the matching command name.

3. Parse

The descriptor's signature id selects resident parser code, which fills CF_* call-frame fields.

4. Execute

The descriptor tells ReadyBASIC which packed code bytes to copy from REU bank $45 and where to call them.

5. Commit

The worker writes RF_* result-frame fields. Resident code commits the result to BASIC only on success.

When To Use PROC/FUNC Instead

Use a native routine when reusable logic is naturally BASIC code and should live in the user's program.

1000 PROC DRAW(P%,N$)
1010 PRINT P%;N$
1020 ENDP

1100 FUNC ADDI(X%,Y%)
1110 R%=X%+Y%
1120 RET R%
1130 ENDP

10 EXEC DRAW(3,"PLAYER")
20 A%=ADDI(4,5)
30 PRINT ADDI(6,7)

PROC has input formals only. FUNC also declares input formals only and returns with RET expr; use RET% expr or RET$ expr when the return type should be explicit. FUNC is called as an expression and does not take a final output actual. V1 supports only % integer and $ string formals, no arrays, locals, plain floating variables, by-reference parameters, or multiple outputs. Definitions should live after END; fall-through into a definition is invalid.

Use a descriptor-backed command overlay when the routine needs hidden RAM, REU handles, fast machine-code loops, direct screen/color memory, or shared command behavior.

Naming Rules

ReadyBASIC names are visible BASIC text, not private tokens. Avoid substrings that C64 BASIC can tokenize inside the command name.

Proof/demo commands use Z.... Array demos use NUM instead of INT. Historical names like PING, ADD16, STRUP, HCRC, SUMAI, and RANGEAI are not aliases.

The current proof/demo names are ZECHO1, ZADD16, ZHIDDENRAM, ZSUMNUMARRAY, ZRANGENUMARRAY, ZTEMPSCRATCH, and ZFAIL. The useful string commands are UPPER and LOWER.

Descriptor Shape

Descriptors are cold-seeded into REU bank $44:$1000-$1FFF. Runtime lookup fetches one 256-byte page, scans eight descriptors, then copies the match to RB_DESC_BUF.

.macro CMD_LOW id, sig, label, endlabel, name
        .byte id, RB_CMD_F_LOW
        .word label - __LOWPACK_RUN__ ; offset in REU bank $45
        .word endlabel - label        ; copy length
        .word 0, 0
        .word label - RB_LOW_BASE     ; run offset from $A900
        .word 0
        .byte sig, .strlen(name)
        .byte name
        .res 16 - .strlen(name), 0
.endmacro
.macro CMD_LOW_ALL id, sig, label, name
        .byte id, RB_CMD_F_LOW
        .word 0                    ; whole LOWPACK
        .word __LOWPACK_SIZE__
        .word 0, 0
        .word label - RB_LOW_BASE
        .word 0
        .byte sig, .strlen(name)
        .byte name
        .res 16 - .strlen(name), 0
.endmacro

.macro CMD_HIDDEN id, sig, label, endlabel, name
        .byte id, RB_CMD_F_HIDDEN
        .word 0, 0
        .word label - __HIDDENPACK_RUN__
        .word endlabel - label
        .word 0
        .word label - RB_HIDDEN_BASE
        .byte sig, .strlen(name)
        .byte name
        .res 16 - .strlen(name), 0
.endmacro
Descriptor fieldWhat it teaches
idInternal command id. It is stable command identity, separate from the command's slot number.
sigParser signature id. This is how lookup chooses which resident parser routine fills the call frame.
label / endlabelAssembler labels that define both the packed-code offset and the exact number of bytes to copy.
RB_CMD_F_LOWFlag saying the worker runs from the low overlay window at $A900.
RB_CMD_F_HIDDENFlag saying the worker runs under BASIC ROM RAM at $A800.
CMD_LOW_ALLUsed when a tiny command wrapper calls shared helpers elsewhere in the low pack, so the whole low pack must be available.

Small Commands

ZECHO1

low overlayoutput int

Minimum output-command skeleton: parse OUT%, stage integer 1, commit.

parse_sig_zecho1:
        jsr rb_parse_out_int
        rts

cmd_zecho1_low:
        lda #0
        sta RF_STATUS
        lda #RB_VAL_INT
        sta RF_TAG
        lda #1
        sta RF_VAL_LO
        lda #0
        sta RF_VAL_HI
        rts
cmd_zecho1_low_end:
CMD_LOW CMD_ZECHO1, SIG_ZECHO1,
        cmd_zecho1_low, cmd_zecho1_low_end, "ZECHO1"
Line or groupTeaching note
parse_sig_zecho1:The resident parser entry selected by SIG_ZECHO1.
jsr rb_parse_out_intCaptures the output integer variable address and clears it before command execution.
cmd_zecho1_low:The overlay worker entry. The descriptor stores this address as an offset from RB_LOW_BASE.
RF_STATUS = 0Marks success. Resident code commits results only when this is zero.
RF_TAG = RB_VAL_INTSays the result frame contains a BASIC integer.
RF_VAL_LO/HI = 1Stages the little-endian integer value that will be written to the captured output variable.
cmd_zecho1_low_end:End marker for copy-size math. It is not an executable target.
CMD_LOW ... "ZECHO1"Publishes the public command name and binds parser signature to worker slice.

ZADD16

low overlaytwo numeric inputs

Proves BASIC ROM expression parsing in resident code, then simple arithmetic in the overlay.

parse_sig_zadd16:
        jsr rb_parse_num0
        jsr rb_parse_num1
        jsr rb_parse_out_int
        rts

cmd_zadd16_low:
        clc
        lda CF_NUM0_LO
        adc CF_NUM1_LO
        sta RF_VAL_LO
        lda CF_NUM0_HI
        adc CF_NUM1_HI
        sta RF_VAL_HI
        lda #0
        sta RF_STATUS
        lda #RB_VAL_INT
        sta RF_TAG
        rts
CMD_LOW CMD_ZADD16, SIG_ZADD16,
        cmd_zadd16_low, cmd_zadd16_low_end, "ZADD16"
Line or groupTeaching note
rb_parse_num0, rb_parse_num1Resident parser helpers evaluate BASIC numeric expressions into CF_NUM0_* and CF_NUM1_*.
rb_parse_out_intCaptures the integer output target and clears it before execution.
clcClears carry before two-byte addition. Without this, stale CPU carry would corrupt the result.
adc CF_NUM1_LOAdds low bytes and leaves carry ready for the high-byte addition.
adc CF_NUM1_HIAdds high bytes plus carry, producing a 16-bit result.
RF_VAL_LO/HIHolds the staged result. The overlay does not write BASIC variables directly.
CMD_LOW ... "ZADD16"The descriptor connects the visible command to this parser and this exact low-overlay copy range.

String Commands

UPPER and LOWER share parse_sig_string_out. The overlay transforms bytes into RF_STR_BUF; resident code owns BASIC string heap allocation.

parse_sig_string_out:
        jsr rb_parse_string_value
        jsr rb_parse_out_string
        rts

cmd_lower_low:
        lda #0
        sta RF_STATUS
        lda #RB_VAL_STRING
        sta RF_TAG
        lda CF_STR_LEN
        sta RF_STR_LEN
        ldy #0
@loop:
        cpy CF_STR_LEN
        beq @done
        lda CF_STR_BUF,y
        cmp #'A'
        bcc :+
        cmp #'Z' + 1
        bcs :+
        clc
        adc #$20
:       sta RF_STR_BUF,y
        iny
        jmp @loop
@done:
        rts
CMD_LOW CMD_UPPER, SIG_UPPER,
        cmd_upper_low, cmd_upper_low_end, "UPPER"
CMD_LOW CMD_LOWER, SIG_LOWER,
        cmd_lower_low, cmd_lower_low_end, "LOWER"
Line or groupTeaching note
parse_sig_string_out:Shared parser shape for commands that take one string value and one output string variable.
rb_parse_string_valueAccepts a string expression or literal and stages the bytes in CF_STR_BUF.
rb_parse_out_stringCaptures the destination string variable. BASIC string heap mutation is still resident-code work.
RF_STR_LEN = CF_STR_LENCopies the input length because case conversion preserves length.
@loop / cpy CF_STR_LENWalks the staged string one byte at a time using Y as the index.
cmp #'A' ... adc #$20Converts ordinary ASCII uppercase bytes to lowercase bytes.
sta RF_STR_BUF,yWrites transformed bytes to the result frame, not directly to BASIC string memory.
CMD_LOW ... "UPPER"/"LOWER"Two public commands share the same parser shape but point at different byte-transform workers.

The source also handles shifted C64 letter bytes. Tests assert ASC() values because visual case depends on the active C64 charset.

Array And Hidden Examples

ZHIDDENRAM

Uses CMD_HIDDEN, fetches code into $A800, maps RAM under BASIC ROM, runs a checksum-like worker, and restores banking.

CMD_HIDDEN CMD_ZHIDDENRAM, SIG_ZHIDDENRAM,
           cmd_zhiddenram_hidden, cmd_zhiddenram_hidden_end,
           "ZHIDDENRAM"

ZSUMNUMARRAY

Uses an explicit base element plus count: ZSUMNUMARRAY(A%(0),3,S%). Resident code resolves the array pointer before the overlay runs.

parse_sig_zsumnumarray:
        jsr rb_parse_int_array_input
        jsr rb_parse_out_int
        jsr rb_resolve_int_array_input_ptr
        rts

ZRANGENUMARRAY

Output-array sibling for ZSUMNUMARRAY. It proves the result-frame path for writing several integer elements after the command has succeeded.

parse_sig_zrangenumarray:
        jsr rb_parse_num0
        jsr rb_parse_num1
        jsr rb_parse_int_array_output
        rts

cmd_zrangenumarray_low:
        ; stage output bytes in RF_ARR_BUF
        ; resident commit copies them into A%()
CMD_LOW CMD_ZSUMNUMARRAY, SIG_ZSUMNUMARRAY,
        cmd_zsumnumarray_low, cmd_zsumnumarray_low_end,
        "ZSUMNUMARRAY"
CMD_LOW CMD_ZRANGENUMARRAY, SIG_ZRANGENUMARRAY,
        cmd_zrangenumarray_low, cmd_zrangenumarray_low_end,
        "ZRANGENUMARRAY"
Line or groupTeaching note
rb_parse_int_array_inputParses a base element such as A%(0) plus a count. The base element matters because BASIC arrays are not passed as whole objects.
rb_resolve_int_array_input_ptrConverts the parsed array reference into a direct pointer in CF_PTR0_LO/HI.
ldy #1 then deyReads the low byte and high byte of each C64 integer array element.
adc #2Advances the indirect pointer to the next two-byte integer element.
ZRANGENUMARRAYDemonstrates the sibling pattern: stage multiple output values first, then let resident commit write the BASIC array after success.
CMD_LOW ... "ZSUMNUMARRAY"Publishes a read-array proof command. The name uses NUM, not INT, to avoid the BASIC tokenizer trap.

REU Handle Commands

BASIC sees a small integer handle. Canonical descriptors live in REU bank $44:$0800-$09FF, the bitmap at $44:$0C00, and data in the 48KB typed heap at $44:$4000-$FFFF.

CommandPattern
BUFNEWAllocate pages, store type-1 descriptor, return one-based handle.
BUFFILLValidate type-1 buffer handle, fill pages through $C500.
BUFFREEFree any valid handle type and clear metadata.
SCRCAPAllocate type-2 screen text+color handle and stash text/color RAM.
SCRPUTValidate type-2 handle and restore text/color RAM from slot-128 lookup.
 
cmd_bufnew_low:
        jsr rb_handle_alloc
        rts

cmd_scrput_low:
        jsr rb_screen_handle_validate
        lda RF_STATUS
        beq :+
        rts
:       jsr rb_screen_load_text
        jsr rb_screen_load_color
        lda #0
        sta RF_STATUS
        lda #RB_VAL_NONE
        sta RF_TAG
        rts
CMD_LOW_ALL CMD_BUFNEW, SIG_BUFNEW, cmd_bufnew_low, "BUFNEW"
CMD_LOW_ALL CMD_BUFFILL, SIG_BUFFILL, cmd_buffill_low, "BUFFILL"
CMD_LOW_ALL CMD_BUFFREE, SIG_BUFFREE, cmd_buffree_low, "BUFFREE"
CMD_LOW_ALL CMD_SCRCAP, SIG_SCRCAP, cmd_scrcap_low, "SCRCAP"
CMD_LOW_ALL CMD_SCRPUT, SIG_SCRPUT, cmd_scrput_low, "SCRPUT"
Line or groupTeaching note
rb_handle_allocFinds a free handle id, reserves heap pages in REU, writes canonical metadata, and stages the handle number as an integer result.
rb_handle_fillValidates that the handle is a generic buffer before writing data. This is where type safety lives.
rb_handle_freeAccepts any valid typed handle and releases both descriptor metadata and heap pages.
rb_screen_handle_allocAllocates a type-2 screen text+color handle, sized for the screen snapshot resource.
lda RF_STATUS / beq :+Stops immediately if allocation or validation failed, preserving the error status for resident code.
rb_screen_save_text/colorCopies text RAM and color RAM into the typed REU handle.
rb_screen_load_text/colorRestores text RAM and color RAM only after the handle type has been validated.
CMD_LOW_ALL ...These commands call shared helpers, so the descriptor copies the whole low pack instead of just the wrapper bytes.

The handle lesson is to keep BASIC-visible values small, keep canonical resource metadata in REU, and validate handle type at command boundaries. BUFFILL accepts only type-1 buffer handles; SCRPUT accepts only type-2 screen text+color handles; BUFFREE frees any valid type.

Naming Lessons And Add-Command Checklist

  1. Choose a tokenizer-safe name.
  2. Add command id and signature id.
  3. Add or reuse a parser signature that fills the call frame and clears outputs.
  4. Add a low or hidden worker that writes the result frame only on success.
  5. Add a descriptor entry; use CMD_LOW_ALL only when shared helpers require the full low pack.
  6. Keep resident growth minimal; prefer REU metadata and existing scratch pages.
  7. Add direct, stored-program, error-path, and resume/slot coverage.
  8. Update Markdown and HTML docs with measured map values after tests pass.

Appendix: Descriptor And Registry Labels

REGSEEDCold-load descriptor image. It is copied to REU and then reclaimed so BASIC free bytes do not shrink.
RB_CMD_DESC_COUNTRegistry capacity, currently 128 command descriptors.
$44:$1000-$1FFFREU location of the descriptor table. Lookup pages through this range.
RB_PAGEBUFRAM page buffer used to fetch one 256-byte descriptor page, eight descriptors at a time.
RB_DESC_BUFResident copy of the single matched descriptor.
__LOWPACK_RUN__Linker symbol for the packed low-overlay image before prestash to REU bank $45.
__LOWPACK_SIZE__Measured full low-pack size, currently $061A.
RB_LOW_BASERuntime low-overlay base address, currently $A900.
RB_HIDDEN_BASERuntime hidden-overlay base address, currently $A800.

Expression-Style Experiment

The 2026-05-23 expression branch adds bare statement calls and an eval-vector hook for a small expression-safe subset. Commands can run as ZADD16(4,5,A%) or return values as ZADD16(5,10) and UPPER("ready"). Commands with array outputs or no scalar result remain statement-only; scalar handle returns such as BUFNEW(n) and SCRCAP() are expression-enabled.

Native routines accept parenthesized non-empty argument lists: PROC SHOWI(P%) and EXEC SHOWI(7). FUNC routines return through RET expr, with optional RET% expr and RET$ expr markers. Expression calls run simple scalar assignments before RET; calls such as A$=GREET("READY") or PRINT ADDI(6,7) return the RET expression directly.
