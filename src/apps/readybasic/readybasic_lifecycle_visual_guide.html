Lifecycle And Memory

ReadyBASIC has two memory stories. Cold load briefly carries seed bytes in the PRG image. After BASIC is initialized, the seed is copied into REU, the BASIC workspace starts at $2AC1, and module code is fetched on demand into RAM hidden behind BASIC ROM.

Lifecycle

Cold Entry

Copy hidden/common helper to $A000, bridge to $C000, registry to REU $44, and built-in payloads to REU $45.

BASIC Ready

Initialize BASIC pointers so $2AC1-$9FFF is normal workspace. Seed bytes are disposable.

Command Call

Parse in resident code, fetch descriptor from REU, copy payload from $45 only when needed, execute under BASIC ROM, commit result.

Warm Resume

Re-mark REU banks, restore hooks/snapshots, and reuse registry, handles, modules, and payloads already in REU.

Built-in payload bytes occupy $0000-$085B. Disk sample payloads currently use $3000, $3200, $3300, and $3400.
