Technical Philosophy

ReadyBASIC is a ReadyOS-native BASIC host, not a normal C64 BASIC PRG and not a cc65 application. Its current plugin spine is all assembler and intentionally small: no object VM, no generic value serializer, no command-per-bank REU waste, and no custom token cruncher in V1.

The central rule: BASIC-facing work stays in visible resident RAM. Workers receive a flat call frame, write a flat result frame, and let the resident core commit results back into BASIC.

Visible resident core

Owns ROM helper calls, parsing, variable references, string heap writes, REU DMA wrappers, and result commit.

Low and hidden overlays

Do command work from copied slices. They do not own BASIC's live interpreter contracts.

REU banks

Hold registry, frames, code pack, debug snapshots, and sample handle data without spending normal BASIC RAM per command.

Cold Boot Flow

Cold boot starts with a plain ReadyOS app load at `$1000`. The tiny entry code does the minimum work needed before handing control to the resident core.

1

Load

ReadyOS loads readybasic.prg at `$1000`.

2

Copy Hidden

Entry maps RAM under BASIC ROM and copies hidden helper seed to `$A000` and `$9A00`.

3

Copy Bridge

Bridge seed from `$3800` becomes live state at `$C000`.

4

Initialize BASIC

Resident sets `$3001` workspace, `$9600` top, and clears `$3000-$3002`.

5

Seed REU

Hidden helper prestashes registry to `$44` and code pack to `$45`, then enters READY.

Cold-only behavior: registry and code are copied from load-only RAM into REU. Warm resume re-marks bank ownership but avoids rereading `$4000+` because BASIC may own that memory by then.

Suspend And Resume

EXIT suspend

The execute hook recognizes EXIT. Manual prompt EXIT is the proven V1 path. It stores READY-mode magic, saves BASIC runtime state under `$9600`, restores page-3 vectors, and jumps to the ReadyOS shim at `$C80C`.

RangeSaved data
$9600-$96FFZero page snapshot.
$9700-$97FFHardware stack snapshot.
$9800+Magic, saved SP, mode, line-chain guards.
$9A00-$9FFFHidden helper shadow preserved inside app snapshot.

Warm resume

On relaunch from the ReadyOS menu, entry-local magic selects warm path. ReadyBASIC restores `$A000` from `$9A00`, reinstalls the execute hook, re-marks REU banks, restores stack and zero page, and redraws the ReadyBasic screen before entering `BASIC_READY`.

Warm restore does not cold-reset BASIC. It preserves live `FRETOP`, `VARTAB`, `ARYTAB`, `STREND`, variables, arrays, and string heap state from the saved runtime image.

Command Pipeline

The current path is raw text at execute time. BASIC `LIST` still shows !COMMAND args; ReadyBASIC recognizes it when ROM BASIC dispatches the statement.

1. Match

Peek at the next non-space byte without disturbing `TXTPTR`. If it is not `!` or `EXIT`, tail-call the saved ROM execute vector.

2. Parse

Normalize command name into `$26A0`, linear-search descriptors from REU bank `$44`, then parse parameters with BASIC ROM helpers.

3. Execute

Copy command code from REU bank `$45` into `$1C00` or `$A800`, call it, and stash call/result frames back into bank `$44` for inspection.

4. Commit

Resident code checks `RF_STATUS`, prints `?RB ERROR n` on failure, or commits integer, string, or array results to the captured BASIC output reference.

Command Code And Data Movement

These commands are representative samples for the plugin spine. Some are tiny single-slice low overlays; the handle commands currently copy the whole low pack to keep allocator helpers out of resident RAM.

!PING OUT%

lowoffset $0000copy $0015

Returns integer `1`. Proves output variable clearing and scalar result commit.

!ADD16 A,B,OUT%

lowoffset $0015copy $001E

Parses two numeric expressions through BASIC ROM and returns a 16-bit sum.

!STRUP S$,OUT$

lowoffset $0033copy $003B

Copies a string variable or quoted literal into the call frame, uppercases it, and lets resident code allocate the BASIC string result.

!HCRC S$,OUT%

hiddenbank $45+$02F3copy $004D

Copies hidden code into `$A800`, maps RAM under BASIC ROM, and returns a checksum-like uppercase byte sum.

!SUMAI A%(0),COUNT,OUT%

lowoffset $006Ecopy $0044

Uses explicit array base plus count, resolves the array pointer, and sums integer elements.

!RANGEAI START,COUNT,A%(0)

lowoffset $00B2copy $003D

Stages consecutive integer values in the result frame; resident code writes them into the output array.

!BUFNEW LEN,H%

lowREU handlecopy $02F3

Allocates contiguous 256-byte pages inside bank `$44` and returns a one-based handle.

!BUFFILL H%,BYTE

lowREU datacopy $02F3

Fills `$2700` with a byte and stashes it page by page into the handle's REU pages.

!BUFFREE H%

lowmetadatacopy $02F3

Clears page bitmap and handle metadata, then mirrors that metadata to bank `$44` offset `$0800`.

!TEMPSCRATCH LEN,OUT%

lowtemp heapcopy $02F3

Allocates and immediately frees pages, returning the number of pages required.

!FAIL CODE,OUT%

lowerror pathcopy $001B

Proves outputs are cleared before execution and stale result frames are not committed after failure.

Hard Invariants

  • Boot through ReadyOS, not standalone app launch.
  • BASIC_START remains $3001.
  • $3000 remains zero before stored-program RUN.
  • RESIDENT stays below $1C00.
  • BRIDGE stays below $C600.
  • $C600-$C7FF is shared ReadyOS REU metadata.
  • $C800-$C9FF is shim ABI, not app scratch.
  • Warm resume restores $A000 from $9A00 before hidden calls.
  • Warm restore preserves live FRETOP, variables, arrays, and string heap.
  • ReadyBASIC restores owned page-3 vectors before yielding to ReadyOS.
  • Fallback BASIC dispatch tail-calls the original $0308 vector with unmutated TXTPTR.
  • String heap writes happen only in visible resident code.
  • Acceptance re-entry uses launcher menu navigation, not CTRL+3.
