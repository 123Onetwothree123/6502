Technical Philosophy

ReadyBASIC is a ReadyOS-native BASIC host, not a normal C64 BASIC PRG and not a cc65 application. Its current plugin spine is all assembler and intentionally small: no object VM, no generic value serializer, no command-per-bank REU waste, and no custom token cruncher in V1.

The central rule: BASIC-facing work stays in visible resident RAM. Workers receive a flat call frame, write a flat result frame, and let the resident core commit results back into BASIC.

Visible resident core

Owns ROM helper calls, parsing, variable references, string heap writes, REU DMA wrappers, and result commit.

Low and hidden overlays

Do command work from copied slices. They do not own BASIC's live interpreter contracts.

REU banks

Hold registry, frames, code pack, debug snapshots, and sample handle data without spending normal BASIC RAM per command.

Cold Boot Flow

Cold boot starts with a plain ReadyOS app load at `$1000`. The tiny entry code does the minimum work needed before handing control to the resident core.

1

Load

ReadyOS loads readybasic.prg at `$1000`.

2

Copy Hidden

Entry maps RAM under BASIC ROM and copies the hidden helper seed to `$A000`, then keeps a visible shadow at `$C280`.

3

Copy Bridge

Bridge seed becomes live state at `$C000-$C1F4`.

4

Initialize BASIC

Resident sets `$2401` workspace, `$A000` top, and clears `$2400-$2402`.

5

Seed REU

Hidden helper prestashes registry to `$44` and code pack to `$45`, then enters READY.

Cold-only behavior: registry and code are copied from load-only RAM into REU. Warm resume re-marks bank ownership but avoids rereading `$2800+`, `$4000+`, `$4800+`, or `$5000+` because BASIC may own that memory by then.

Suspend And Resume

EXIT suspend

The execute hook recognizes EXIT. Manual prompt EXIT is the proven V1 path. It stores READY-mode magic, saves BASIC runtime state to REU bank `$44`, restores page-3 vectors, and jumps to the ReadyOS shim at `$C80C`.

RangeSaved data
REU $44:$0A00Zero page snapshot.

Warm resume

On relaunch from the ReadyOS menu, entry-local magic selects warm path. ReadyBASIC restores `$A000` from `$C280`, reinstalls the execute hook, re-marks REU banks, restores stack and zero page, and redraws the ReadyBasic screen before entering `BASIC_READY`.

Warm restore does not cold-reset BASIC. It preserves live `FRETOP`, `VARTAB`, `ARYTAB`, `STREND`, variables, arrays, and string heap state from the saved runtime image.

Command Pipeline

The current path is raw text at execute time. BASIC `LIST` still shows COMMAND(...); ReadyBASIC recognizes it when ROM BASIC dispatches the statement.

1. Match

Peek at the next non-space byte without disturbing `TXTPTR`. If it is not `EXIT`, a routine keyword, or a known command name followed by parentheses, tail-call the saved ROM execute vector.

2. Parse

Normalize command name into `$C4A0`, fetch descriptor pages from REU bank `$44`, scan eight descriptors per page, then parse parameters with BASIC ROM helpers.

3. Execute

Copy command code from REU bank `$45` into `$A900` or `$A800`, call it, and stash call/result frames back into bank `$44` for inspection.

4. Commit

Resident code checks `RF_STATUS`, prints `?RB ERROR n` on failure, or commits integer, string, or array results to the captured BASIC output reference.

Command Code And Data Movement

These commands are representative samples for the plugin spine. Some are tiny single-slice low overlays; the handle and screen commands currently copy the whole low pack to keep REU descriptor, bitmap, and allocator helpers out of resident RAM.

ZECHO1(OUT%) / ZECHO1()

low $A900offset $0000copy $0015 / 21B

Returns integer `1`. Proves output variable clearing and scalar result commit.

ZADD16(A,B,OUT%) / ZADD16(A,B)

low $A900offset $0015copy $001E / 30B

Parses two numeric expressions through BASIC ROM and returns a 16-bit sum.

UPPER(S$,OUT$) / UPPER(S$)

low $A900offset $0033copy $003B / 59B

Copies a string variable or quoted literal into the call frame, uppercases it, and lets resident code allocate the BASIC string result.

LOWER(S$,OUT$) / LOWER(S$)

low $A900offset $006Ecopy $003B / 59B

Lowercases string byte values. Tests check ASC() output because visual lowercase depends on the active C64 character set.

ZHIDDENRAM(S$,OUT%) / ZHIDDENRAM(S$)

hiddenbank $45+$061Bcopy $004D / 77B

Copies hidden code into `$A800`, maps RAM under BASIC ROM, and returns a checksum-like uppercase byte sum.

ZSUMNUMARRAY(A%(0),COUNT,OUT%) / ZSUMNUMARRAY(A%(0),COUNT)

low $A900offset $00A9copy $0044 / 68B

Uses explicit array base plus count, resolves the array pointer, and sums integer elements.

ZRANGENUMARRAY(START,COUNT,A%(0))

low $A900offset $00EDcopy $003D / 61B

Stages consecutive integer values in the result frame; resident code writes them into the output array.

BUFNEW(LEN,H%) / BUFNEW(LEN)

low $A900REU handlecopy $061B / 1.5K

Allocates contiguous 256-byte buffer pages inside bank `$44` and returns a one-based handle.

BUFFILL(H%,BYTE)

low $A900REU datacopy $061B / 1.5K

Fills `$C500` with a byte and stashes it page by page into a type-1 buffer handle.

BUFFREE(H%)

low $A900metadatacopy $061B / 1.5K

Clears the REU-backed page bitmap and handle descriptor for any valid handle type.

ZTEMPSCRATCH(LEN,OUT%) / ZTEMPSCRATCH(LEN)

low $A900temp heapcopy $061B / 1.5K

Allocates and immediately frees pages, returning the number of pages required.

ZFAIL(CODE,OUT%)

low $A900error pathcopy $001B / 27B

Proves outputs are cleared before execution and stale result frames are not committed after failure.

FREEMEM()

low $A900offset $0155copy $0016 / 22B

Prints current live BASIC free bytes and refreshes the header.

SCRCAP(H%) / SCRCAP()

slot 14screen handlecopy $061B / 1.5K

Captures `$0400-$07E7` screen text and `$D800-$DBE7` color RAM into a type-2 handle.

SCRPUT(H%)

slot 128screen handlecopy $061B / 1.5K

Validates a type-2 handle, then restores screen text and color RAM.

Hard Invariants

  • Boot through ReadyOS, not standalone app launch.
  • BASIC_START remains $2401.
  • $2400 remains zero before stored-program RUN.
  • RESIDENT stays below $2400.
  • BRIDGE stays below $C200, leaving $C200-$C5FF for shared frames.
  • $C600-$C7FF is shared ReadyOS REU metadata.
  • $C800-$C9FF is shim ABI, not app scratch.
  • Warm resume restores $A000 from $C280 before hidden calls.
  • Warm restore preserves live FRETOP, variables, arrays, and string heap.
  • ReadyBASIC restores owned page-3 vectors before yielding to ReadyOS.
  • Fallback BASIC dispatch tail-calls the original $0308 vector with unmutated TXTPTR.
  • String heap writes happen only in visible resident code.
  • Acceptance re-entry uses launcher menu navigation, not CTRL+3.
